# Лабораторные работы по дифференциальной геометрии

Содержимое:

1. `lab_01_2_3_cassini.ipynb` — задача 2.3.
2. `lab_02_2_7_2_9_2_12_curves.ipynb` — задачи 2.7, 2.9, 2.12.
3. `lab_03_4_8_4_13_frenet.ipynb` — задачи 4.8, 4.13.
4. `lab_04_5_2_5_8_surfaces_tangent.ipynb` — задачи 5.2а,б и 5.8б,г,и.
5. `lab_05_6_2_6_8_6_11_6_12_metric.ipynb` — задачи 6.2, 6.8, 6.11, 6.12.
6. `lab_06_6_16_angle_bisectors.ipynb` — задача 6.16.
7. `lab_07_7_18_dupin.ipynb` — задача 7.18.
8. `analytical_solutions.md` — подробные аналитические решения ко всем задачам.

В ноутбуках оставлены постановки задач и динамические визуализации на
`matplotlib.animation.FuncAnimation`. Подробные аналитические решения вынесены
в соседний markdown-файл `notebooks/analytical_solutions.md`.

Файл `lab_1.ipynb` оставлен как старая версия первой лабораторной.
